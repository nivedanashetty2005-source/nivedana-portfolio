# Nivedana Shetty CC — Portfolio Website

A responsive, dark navy and blue portfolio website for entry-level Full-Stack Developer opportunities.

## Files
- `index.html` — page content and project links
- `style.css` — layout, responsive styles, and visual design
- `script.js` — mobile navigation and current footer year

## Run locally
Open `index.html` in a browser. Google Fonts are loaded online; the page otherwise uses plain HTML, CSS, and JavaScript.

## Before publishing
1. Confirm your LinkedIn profile URL before publishing.
2. Confirm the Student Registration repository URL is correct and public.
3. Add a downloadable resume PDF if you want a resume button/link.
4. Deploy the folder using GitHub Pages, Netlify, or Vercel static hosting.
